### 2026-05-30 15:22 05b/05c manual ROI trace prior

背景：

- 发现 05b 只根据手画 ROI 的面积、圆度、长宽比等形状信息建立 prior，不足以判断 ROI 是否像真实细胞
- 查阅 suite2p ROI classification 说明后确认，suite2p 自身也会参考 neuropil-corrected fluorescence trace 的 skew 等信号特征
- 因此 05b/05c 应同时保留形状信息和 trace 质量信息

  - `trace_robust_snr`
  - `trace_dff_p95`
  - `trace_event_fraction_z3`
  - `trace_lag1_autocorr`
- `manual_roi_prior.json` 增加 `trace_metrics` 和 `recommended_trace_rules`
- `manual_roi_table.csv` 增加每个手画 ROI 的 trace 特征
- 新增 `manual_roi_trace_summary.csv`
- 新增 trace dF/F-like amplitude 和 robust SNR 的 PNG/PDF 分布图
- `05c_roi_quality_filter.py` 增加 suite2p ROI trace 质量计算，读取 `F.npy/Fneu.npy`
- 05c 输出表增加 `trace_prior_score`、`trace_cv`、`trace_robust_snr`、`trace_dff_p95` 等列

- `run_pipeline.py` 增加 `05b manual ROI prior`
