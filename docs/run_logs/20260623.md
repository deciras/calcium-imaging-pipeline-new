## Step 12 cluster normalization 开关

为层次聚类增加明确 raw/normalized 开关，并接入 dashboard：

修改文件：

- `current/analysis/12_hierarchical_clustering.py`
- `current/run_pipeline.py`
- `current/pipeline_dashboard_gui.py`
- `current/README.md`
- `docs/run_logs/20260623.md`

新增参数：

```bash
--cluster-normalization normalized
--cluster-normalization raw
--cluster-normalization both
```

含义：

- `normalized`：默认主线；对 trace 或 angle response matrix 做 row-wise z-score 后聚类，强调响应模式。
- `raw`：直接用原始矩阵聚类，保留幅度差异。
- `both`：写 normalized 主输出，同时额外写一套 `raw_cluster_*` 对照输出。

默认距离策略：

- normalized clustering 默认使用 `correlation` distance。
- raw clustering 默认使用 `euclidean` distance，避免 correlation 把 raw 幅度差异抵消掉。
- 如果显式传入 `--distance-metric`，则使用用户指定的距离。
