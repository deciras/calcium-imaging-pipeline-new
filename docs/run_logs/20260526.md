### Fiji 内存问题

- 第一次运行 step 01 时，第一个 trial 成功，第二个 trial Java heap OOM
- 原因：worker 一次性复制完整通道栈再做 Z projection
- 数据规模：`2 channel x 9 Z x 1100 timepoints`
- 增加投影策略：

```text
auto
safe
fast
```

- `auto`：默认，小文件快模式，大文件省内存模式
- `safe`：逐 timepoint Z projection，内存更稳
- `fast`：整通道复制后投影，更快但更吃内存

### OIR 绝对时间戳

- `.oir` 内部 XML 可读到绝对采集开始时间
- 示例：

```text
<base:creationDateTime>2026-04-28T17:04:11.070+08:00</base:creationDateTime>
```

- 文件修改时间减去采集时长只作为兜底
- step 01 metadata 增加：

```json
{
  "acquisition": {
    "start_time": "2026-04-28T17:04:11.070+08:00",
    "start_time_source": "oir_base_creationDateTime"
  }
}
```

- step 02 优先使用 metadata 中的 `acquisition.start_time`
