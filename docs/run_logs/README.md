# 运行日志规则

日志按日期保存：

```text
docs/run_logs/YYYYMMDD.md
```

规则：

1. 先读取系统日期。
2. 查看已有日志文件。
3. 按任务实际开始时间和发生日期归档。
4. 如果一次任务跨越多个日期，分别更新所有相关日期日志。
5. 不把所有内容都堆到当天日志里。
6. 写成实验进度笔记，不写成对话记录。
7. 避免“我今天……”“用户指出……”“Codex 修改……”这类口吻。
8. 优先记录真实运行、代码改动、失败原因、验证结果和下一步计划。

建议结构：

```text
# YYYYMMDD 运行日志

## 概要
## Progress
## Issues / Notes
## Next
## Future
## 今日结论
```
