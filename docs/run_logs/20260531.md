### 2026-05-31 15:55 05e ROI 显示和快捷校对优化

修改内容：

- suite2p ROI 改为显示原始像素边界，不再用圆圈近似
- 增加 `reject` 和 `delete` 的差异：
  - `reject`：保留记录，但后续不用
  - `delete`：从人工校对输出中移除
- 增加快捷键：
  - `Delete` / `Backspace`：删除当前 ROI
  - `X`：reject 当前 ROI
  - `K`：keep 当前 ROI
  - `Ctrl+Z` / `U`：撤销上一步 keep/reject/delete/add
  - `Esc`：撤销当前多边形最后一个点
  - `Enter`：完成当前多边形 ROI
- 保存时新增：
  - `<trial>_kept_suite2p_indices.csv`
  - `<trial>_rejected_suite2p_indices.csv`
  - `<trial>_deleted_suite2p_indices.csv`
