### 2026-05-31 15:26 05e manual ROI curation GUI

新增脚本：

```text
current/05e_roi_curation_gui.py
```

功能：

- 打开一个桌面 GUI，用于人工检查 suite2p ROI
- 左侧显示视频和 suite2p ROI overlay
- 右侧显示原视频，用于手动画新 ROI
- 支持把已有 suite2p ROI 标记为 keep / reject
- 支持用多边形手动画新 ROI，不再限制为圆形
- 选中 ROI 后实时查看 trace
- trace 同时显示 `F`、`Fneu`、`F - 0.7Fneu` 和 dF/F
- 手画 ROI 的 neuropil 用 ROI 周围一圈像素近似估计
- 输出单独保存，不改写 suite2p 原始文件
