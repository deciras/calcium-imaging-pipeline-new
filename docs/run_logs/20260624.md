### Slice response decision

`stimulus_evoked_flag` is true only when all three evidence groups pass:

- `amplitude_pass`: normalized peak z >= 3, or mean z >= 1.5 with positive AUC >= 1.0.
- `latency_pass`: sustained crossing occurs within 3 s after stimulus onset.
- `recovery_pass`: after stimulus offset, signal returns to abs(z) <= 1 within 6 s, or the offset window mean abs(z) is <= 1. If there is no available offset window, recovery is not treated as a hard failure.

The softer `stimulus_response_score` is kept for ranking/QC so borderline photoreceptor responses are not hidden by the binary flag.
