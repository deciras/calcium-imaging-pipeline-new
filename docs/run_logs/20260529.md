### 2026-05-29 16:29 05c ROI quality filter

新增脚本：

```text
current/05c_roi_quality_filter.py
```

功能：

- 读取 `05_suite2p_roi_detection` 的 suite2p ROI
- 读取 `05b_manual_roi_prior/manual_roi_prior.json`
- 根据手画 ROI 的面积、等效直径、长宽比、圆度筛选 ROI
- 不修改原始 suite2p 输出
- 输出 curated ROI 标记、接受/拒绝 index、质量表、overlay 图和 per-trial summary

默认规则：

```text
min_quality_score: 0.75
rule_padding_fraction: 0
require_suite2p_iscell: false
```

含义：

- 4 个形状检查中至少 3 个通过
- 不额外放宽手画 ROI 的 p05-p95 范围
- 不强制要求 suite2p 原本判为 cell，因此仍可救回一部分 suite2p 漏判 ROI

参数比较：

- `min_quality_score 0.75 + rule_padding_fraction 0.25`：过宽，每个 trial 约 691-824 个 ROI
- `min_quality_score 1.0 + rule_padding_fraction 0`：过严，每个 trial 约 2-20 个 ROI
- `min_quality_score 0.75 + rule_padding_fraction 0`：较平衡，每个 trial 约 188-313 个 ROI
