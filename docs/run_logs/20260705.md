### 代码层修改

#### 1. 去掉 trial context 的个人 notes 路径

- `trial_context_utils.py` 不再内置作者私有绝对路径。
- notes 根目录现在优先顺序是：

这样即使别人没有作者本机的 Evernote 迁移目录，也不会因为私有路径残留而产生误导。

#### 2. Fiji 默认发现逻辑改成通用候选

  - `/usr/local/Fiji`、`/usr/local/Fiji.app`

#### 3. Dashboard 默认 Fiji 路径去机器化

- `pipeline_dashboard_gui.py` 不再把 Linux 默认 Fiji 路径写死成某个用户名目录。
- 改成按平台搜索常见 Fiji 位置；都找不到时保持空白，由用户自己选择或保存默认值。

#### 4. Linux dashboard launcher 的 conda 发现逻辑通用化

  - `~/anaconda3/bin/conda`

- 如果都没有，再回退到 `conda`。

这样 Linux 入口不再默认绑定到作者的 home 路径。

#### 5. cleanup 工具改成安全 CLI

- `current/tools/cleanup_pipeline_outputs.py` 之前带着固定根目录，且运行就直接删。
- 现在改成：
  - 必须显式传 `root_dir`
  - 默认只 preview
  - 只有加 `--execute` 才真的删除

这一步是直接降低误删风险，不只是改好看。
